# ***🛋️ АИС Мебельный магазин***
FurnitureStore IS — полнофункциональная информационная система, предназначенная для автоматизации работы мебельного магазина. Система предоставляет инструменты для управления товарами, заказами, клиентами и складом, а также аналитику для принятия бизнес-решений.

## ✨ Возможности

### 🏪 *Управление магазином*
- Каталог товаров - полное управление ассортиментом мебели
- Управление товарами - отслеживание остатков на складе, автоматическое списание
- Категории и коллекции - удобная систематизация товаров
  
### 👥 *Работа с клиентами*
- Клиентская база - учет постоянных клиентов и их предпочтений
- История заказов - полная история взаимодействий с клиентами
- Система скидок - гибкая система лояльности
  
### 📦 *Управление заказами*
- Оформление заказов - быстрый процесс от выбора товара до оформления
- Статусы заказов - отслеживание этапов выполнения (новый, в работе, доставка, выполнен)
- Управление доставкой - планирование и отслеживание доставки
  
### 📊 *Аналитика и отчетность*
- Дашборд аналитики - ключевые метрики продаж и популярности товаров
- Финансовые отчеты - анализ выручки, прибыли, среднего чека
- Отчеты по товарам - анализ движения товаров, выявление хитов продаж

Этот проект разработан в рамках курсовой работы по дисциплине "Разработка информационных систем".
